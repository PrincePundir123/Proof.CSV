      ASK. EXECUTE. VERIFY.

      An answer you can inspect.

      ProofCSV turns a spreadsheet question into Python code, executes it in a disposable sandbox, and returns the actual files and logs.

      1. You ask.Upload a CSV and describe the result you want.
      2. The agent plans.Vultr Inference writes the plan and code. Execution errors can trigger one visible repair attempt.
      3. The sandbox works.A separate, offline container runs the code with time, memory, and process limits.
      4. You inspect.Get the computed report, downloadable files, executed code, logs, and artifact hashes. The container is destroyed.

      The sample preview uses bundled data and does not call an AI model or run a sandbox.
